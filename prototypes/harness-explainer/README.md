# Harness 架构解释样本

## 打开

直接双击 `index.html`。脚本、样式和原文均已内嵌，查看无需安装依赖或启动服务器。

先看整体。选择模块后，局部成为主视图；按“执行流程、内部结构、对外关系”阅读。选择步骤、组成部分或连接，可查看详情与原文依据。“上一处”返回阅读位置，“回到总览”清空当前选择。切换模块或返回上一处时，保留该模块的页签与条目选择。阅读状态仅在本次打开期间保留。

## 本次确认的范围

- 素材：同一问题的多轮讨论。本例为《分析 DeepSeek Harness 核心插件》的两轮回答及原分析附件。

- 交付：单文件 HTML、制作源码、变化记录与可恢复旧版。

## 制作与更新

构建需要 Node.js 24+；阅读成品不需要 Node.js。

```sh
npm ci
npm run preview:build
```

临时预览位于 `.preview/index.html`，不会产生正式版本。修改 `src/content.ts`、`src/details.ts` 和来源材料后，生成正式版本：

```sh
npm run build -- --note "本次内容变化的简述"
```

构建会核对所有摘录是否存在于原文中，保存 HTML 和源码快照到 `versions/vNNN/`，再更新固定入口 `index.html`。内容不变时复用既有版本。未归档的手工 HTML 改动会阻止覆盖。

每次主动调用更新时，制作方需要实际合并新讨论并填写变化说明；本样本没有自动收集聊天的后台服务。

## 恢复

```sh
npm run restore -- v001
```

恢复固定入口的 HTML，并校验归档哈希。工作源码不自动回退，旧源码仍保存在对应版本目录。阅读位置恢复与内容版本恢复是两件不同的事。
