## 本轮确认

- **读者与材料**：面向参与过对话的人，串起同一主题的多轮讨论。
- **理解目标**：看清主要部分、职责及连接，再按需深入局部。
- **视觉主体**：总览用于建立整体认识；选中后，局部成为主要阅读区域，整体收起为导航。
- **局部内容**：按内容选择执行流程、内部结构、对外关系；静态概念无需强行编造流程。
- **来源边界**：关系不清先核对来源、询问用户；用户无法澄清时按上下文推理，标明推断并保留合理分支或缺口。
- **文字**：短句、短标签，去掉重复解释，细节与依据按需展开。
- **网页实现**：默认 React + TypeScript + Tailwind CSS + Headless UI；交付可直接打开的自包含 HTML，并保留源码。
- **更新**：主动调用或请求修改时更新同一入口，记录变化并保留可恢复旧版；跨模块返回保留局部阅读位置。
- **验收**：由用户明确决定，技术检查不能代替验收。
